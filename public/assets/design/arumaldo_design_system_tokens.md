## 0. Executive Summary of This Update

The original `arumaldo.com` design export described a clean monochrome technology-partner website. The new brand-guide source expands that into a more complete personal-brand system for **Abdiel Rumaldo Fábrega / @arumaldo**.

The updated system should now feel:

- Personal but professional
- Calm, grounded, and intentional
- Technical without becoming cold
- Entrepreneurial without “hustle bro” energy
- Nature-informed, using the **Cerro Azul** visual origin
- Built around the idea that technology enables solutions, but rarely is the real problem

The most important shift is this:

```text
Old direction: monochrome business/tech partner site.
New direction: personal digital architect brand with a warm, restrained, nature-derived palette.
```

## 6. Design Principles

### 6.1 Primary principles

1. **The slogan leads.** The main message should be the most visible thing in key compositions.
2. **Technology is the enabler, not the hero.** Avoid visuals that over-index on servers, code, dashboards, or generic SaaS imagery.
3. **Restraint communicates confidence.** Use fewer colors, fewer effects, more space.
4. **Warmth matters.** The brand should not feel like a cold IT vendor.
5. **Personal and business should coexist.** Dark professional layouts and warm personal layouts are both part of the same system.
6. **Everything should feel found, not decorated.** The palette comes from Cerro Azul, water, cave, sun, forest, and a MacBook surface.

### 6.2 Visual rules from the brand guide

| Rule | Instruction |
|---|---|
| Slogan treatment | Always pair the slogan with **Deep Cave** and a **Filtered Sun** accent. |
| Philosophy treatment | Use **Living Green** or **Water Veil**. It should support the slogan, not compete with it. |
| Personal content | Use **Matte Silver**, **Warm Paper**, or warm off-white surfaces. |
| Photography | Natural light, park, morning, water, forest, real moments. Nothing staged. |
| Space | Use generous whitespace. Visual silence communicates confidence. |
| Gradients | Avoid gradients. They make the system feel like a template. |
| Shadows | Avoid heavy shadows. Use flat/editorial surfaces. |
| Color restraint | Never use more than 2 dominant colors in one composition. |
| Typography | Avoid decorative typefaces. Use Inter, Sora, or system fonts. |

Inter, Sora, or system font. Never decorative.

Use:

- Natural light
- Forest / park / water settings

- Dark minimal clothing
- Warm tones with green backgrounds
- Documentary feel, not stock

- Overly corporate headshots
- Stock office imagery
- Neon tech backgrounds
- Artificial blue SaaS lighting
- Staged “guru” poses

### 12.2 Illustration / graphic style

Use:

- Flat editorial backgrounds
- Organic cave/water/forest textures
- Negative space
- Single accent line or marker
- Minimal, restrained geometry

Avoid:

- Gradients
- Heavy shadows
- Busy abstract blobs
- Multi-color SaaS illustrations
- Canva-template compositions

| `breakpoint.sm` | `640px` | Large phones |
| `breakpoint.md` | `768px` | Tablets |
| `breakpoint.lg` | `1024px` | Small desktop / nav switch |
| `breakpoint.xl` | `1200px` | Standard desktop container |
| `breakpoint.2xl` | `1440px` | Large desktop |

Recommended behavior:

- Collapse multi-column brand-guide grids below `600px`.
- Mobile nav collapses below `1024px`.
- Service grids collapse below `768px`.
- Typography reduces at `768px` and again at `480px`.
- Keep `16–24px` side padding on mobile.

| Token | Value | Use |
|---|---:|---|
| `a11y.focus.outline` | `2px solid #A8BFB0` | Keyboard focus |
| `a11y.focus.offset` | `3px` | Focus spacing |

- Buttons and links need visible focus states.
- Do not rely on color alone for form errors.
- Keep labels visible; do not use placeholder-only inputs.
- Body text should remain `16px` minimum on the website.
- Small `11px` labels are acceptable only for metadata, not body copy.

The strongest brand signals are now:

3. **Palette:** Deep Cave, Filtered Sun, Water Veil, Living Green, Matte Silver
4. **Voice:** builder, problem solver, not guru, not hustle
5. **Visual restraint:** warm, flat, natural, editorial, spacious
6. **Business clarity:** services, infrastructure, architecture, support, practical outcomes
